# YouTube下載器 v2.0 - 穩定修復版

由 Augment AI 開發的現代化影片下載工具，支援1000+影片網站，具備完整的異常處理和穩定性保證。

## ✨ 主要特色

### 🌐 廣泛支援
- **1000+網站支援** - 基於yt-dlp，支援YouTube、Bilibili、TikTok、QQ影片等
- **智能平台檢測** - 自動識別影片來源並優化下載策略
- **多格式支援** - 支援各種影片和音頻格式

### 🎯 核心功能
- **高品質下載** - 支援最高8K解析度
- **音視頻分離** - 可選擇僅下載音頻或視頻
- **自動合併** - 智能合併音視頻檔案
- **批量下載** - 支援多個影片同時下載
- **穩定可靠** - 完整的異常處理，防止程式崩潰

### 🎨 用戶界面
- **現代化GUI** - 基於PySide6的美觀界面
- **緊湊布局** - 充分利用水平空間的設計
- **即時狀態** - 顯示下載進度和速度
- **完整工具提示** - 每個控件都有清晰的使用說明

### 🔧 進階功能
- **外部工具整合** - 支援多種外部下載服務
- **進階管理器** - 可視化的外部工具管理界面
- **智能錯誤處理** - 提供詳細的錯誤診斷和建議
- **設定管理** - 自動保存用戶偏好設定

## 🚀 快速開始

### 方法一：直接運行EXE（推薦）
1. 下載最新的EXE檔案：`YouTube下載器_v2.0_穩定修復版_由Augment_AI開發.exe`
2. 雙擊運行即可使用
3. 無需安裝Python或其他依賴

### 方法二：從源碼運行
```bash
# 克隆倉庫
git clone https://github.com/JOVIANpega/Youtube_Download.git
cd Youtube_Download

# 安裝依賴
pip install -r requirements.txt

# 運行程式
python main.py
```

## 🎯 使用說明

### 基本下載
1. 啟動程式
2. 在「影片網址」欄位貼上影片連結
3. 選擇下載路徑和品質設定
4. 點擊「🚀 下載」

### 界面布局
```
┌─ 🔗 影片網址 ─────────────────────────────────────────┐
│ [網址輸入框 150字元                              ] [❌] │
│ ✅ 支援：YouTube、Bilibili、TikTok、QQ影片等1000+網站   │
└─────────────────────────────────────────────────────┘

┌─ ⚙️ 下載設定 ─────────────────────────────────────────┐
│ 路徑:[路徑 150字元        ][瀏覽] 前綴:[per-▼][4/15]   │
│ 品質:[最高▼] 解析度:[1080P▼] ☑自動合併音視頻          │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│  [🚀 下載] [🔗 外部工具] [⚙️ 管理] [📁 打開路徑]      │
└─────────────────────────────────────────────────────┘
```

### 進階設定
- **檔名前綴**: 自定義下載檔案的前綴（最多15字元）
- **品質選擇**: 最高、高品質、中等、僅音頻
- **解析度**: 1080P、720P、480P、360P、自動
- **字體大小**: 10-15範圍可調整

### 外部工具管理
- 點擊「🔗 外部工具」使用第三方下載服務
- 點擊「⚙️ 管理」打開進階管理器
- 支援新增、修改、刪除外部工具
- 內建8個熱門下載工具

## 🔧 技術架構

### 核心技術
- **GUI框架**: PySide6 (Qt6)
- **下載引擎**: yt-dlp
- **平台檢測**: 自研智能檢測系統
- **多線程**: 支援並發下載
- **異常處理**: 全局異常捕獲機制

### 穩定性改進
- **安全線程管理** - 避免強制終止線程導致崩潰
- **完整異常處理** - 所有關鍵操作都有try-catch保護
- **資源清理** - 自動清理下載任務和狀態
- **全局異常捕獲** - 防止未處理異常導致程式關閉
