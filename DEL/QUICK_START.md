# 🚀 快速開始指南

## 一鍵啟動

```bash
python start.py
```

就這麼簡單！這個腳本會自動處理一切。

## 📋 啟動流程

### 1. 環境檢查 ✅
- 檢查 Python 版本 (需要 3.7+)
- 檢查 Tkinter 可用性

### 2. 依賴檢查 📦
- 檢查 yt-dlp (下載核心)
- 檢查 requests (FFmpeg下載)
- 自動提示安裝缺失依賴

### 3. 模式選擇 🎯
- **完整版** - 所有功能 (推薦)
- **簡化版** - 基本GUI
- **測試模式** - 檢查問題

## 🎮 使用說明

### 下載視頻
1. 在「下載」分頁輸入視頻網址
2. 選擇下載路徑和品質
3. 點擊「開始下載」
4. 觀看即時進度

### 字體調整
- 點擊右上角 **A-** 減小字體
- 點擊右上角 **A+** 增大字體
- 所有控件即時同步調整

### 查看歷史
1. 切換到「歷史記錄」分頁
2. 搜索、查看統計資訊
3. 右鍵點擊記錄查看選項

### 外部工具
1. 切換到「外部下載器」分頁
2. 輸入網址，點擊「帶網址開啟」
3. 在線上工具中下載

## 🔧 故障排除

### 如果啟動失敗
```bash
# 檢查依賴
python check_dependencies.py

# 手動安裝
python install_deps.py

# 運行測試
python run_tests.py
```

### 如果下載失敗
1. 檢查網路連接
2. 確認 yt-dlp 已安裝
3. 嘗試外部下載器

### 如果界面異常
1. 嘗試簡化版：`python simple_main.py`
2. 檢查 Tkinter 安裝
3. 重置設定檔案
