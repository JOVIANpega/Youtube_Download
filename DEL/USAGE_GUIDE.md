# 🚀 YouTube 下載器 - 使用指南

## 🎯 快速開始

### 立即使用（推薦）

```bash
python main_fixed.py
```

這是修復版，包含所有基本功能，無需額外依賴！

## 📋 功能說明

### 🎨 界面功能

#### 主界面特色
- **500x400 視窗** - 可拖曳調整大小
- **三分頁設計** - 下載、外部工具、歷史記錄
- **A-/A+ 字體控制** - 右上角按鈕，全域字體調整
- **即時設定保存** - 所有設定自動保存

#### 分頁功能

**📥 下載分頁**
- URL 輸入和驗證
- 平台自動檢測（YouTube、Bilibili、TikTok等）
- 下載路徑選擇
- 品質和格式設定
- 檔名前綴設定

**🌐 外部下載器分頁**
- SaveFrom.net 整合
- Y2mate 整合  
- SnapTube 整合
- 一鍵開啟線上工具

**📚 歷史記錄分頁**
- 下載歷史查看
- 搜索和統計
- 檔案存在性檢查
- 批量管理操作

### 🔧 基本操作

#### 驗證視頻網址
1. 在下載分頁輸入視頻網址
2. 點擊「驗證網址」或直接貼上
3. 系統自動檢測平台和有效性

#### 設定下載偏好
1. 選擇下載路徑
2. 設定檔名前綴
3. 選擇視頻品質
4. 點擊「保存設定」

#### 使用外部工具
1. 切換到「外部下載器」分頁
2. 輸入視頻網址
3. 點擊「帶網址開啟」
4. 在線上工具中完成下載

#### 管理歷史記錄
1. 切換到「歷史記錄」分頁
2. 使用搜索框查找記錄
3. 右鍵點擊記錄查看選項
4. 使用底部按鈕進行批量操作

### ⚙️ 進階功能

#### 字體調整
- 點擊右上角 **A-** 減小字體
- 點擊右上角 **A+** 增大字體
- 所有界面元素即時同步調整

#### 設定管理
- 視窗位置和大小自動記憶
- 下載路徑和偏好自動保存
- 字體大小設定持久化

#### 平台支援
支援以下平台的網址檢測：
- YouTube (youtube.com, youtu.be)
- Bilibili (bilibili.com, b23.tv)
- TikTok (tiktok.com)
- 抖音 (douyin.com)
- Instagram (instagram.com)
- Facebook (facebook.com)
- X/Twitter (twitter.com, x.com)
- 微博 (weibo.com)
- 快手 (kuaishou.com)

## 🛠️ 故障排除

### 常見問題

**Q: 應用程式無法啟動？**
A: 請檢查 Python 版本（需要3.7+）和 Tkinter 安裝

**Q: 字體顯示異常？**
A: 使用 A-/A+ 按鈕調整字體大小

**Q: 無法下載視頻？**
A: 修復版僅提供驗證功能，要實際下載請：
```bash
pip install yt-dlp
python main.py
```

**Q: 設定沒有保存？**
A: 確保有寫入權限，設定檔案位於 config/settings.json

### 診斷工具

如果遇到問題，可以使用診斷工具：

```bash
python diagnose.py      # 詳細診斷
python test_fixed.py    # 測試修復版
python simple_test.py   # 快速測試
```
